# Integration Boundaries and Dependencies

## 1. Repository Context (`Risk-ML`)

This project resides independently under `projects/real-time-transaction-risk-platform/` inside the `Risk-ML` workspace.

Neighboring projects in `Risk-ML/projects/` (such as `account-takeover-detection-engine`, `credit-risk-scoring-platform`, `aml-transaction-monitoring-engine`, `chargeback-prediction-engine`, and `graph-based-fraud-detection-engine`) are sibling standalone prototypes. To keep this project independently runnable and avoid fragile cross-project imports, **no direct Python imports from sibling projects are used**.

## 2. Adapter Boundaries

| Boundary | Interface / Class | Prototype Implementation | Optional External Integration |
|---|---|---|---|
| Event Ingestion & State | `FeatureStore` protocol (`src/risk_platform/store.py`) | `InMemoryFeatureStore` (thread-safe, watermarked, atomic JSON checkpoints) | `RedisFeatureStoreAdapter` (explicitly raises `FeatureStoreError` if `redis` package or server is absent; disabled by default via `storage.redis_enabled: false`) |
| Stream Transport | HTTP JSON (`POST /v1/events/ingest`) or direct `service.ingest_event()` | Synchronous Python / FastAPI adapter | Kafka / Redpanda consumer adapter (out of scope for offline prototype; `storage.kafka_enabled: false`) |
| Model Inference | `RiskModelBackend` protocol (`src/risk_platform/model.py`) | `CalibratedLinearRiskModel` (`rtrp.model.v1` JSON + SHA-256) | Swappable with ONNX/XGBoost/remote gRPC scorer implementing `predict(FeatureVector)` |
| Audit & Replay | `AuditLogger` (`src/risk_platform/audit.py`) | Append-only hash-chained JSONL file (`reports/audit_log.jsonl`) | Object storage / WORM compliance sink |

## 4. Fixture Provenance

All fixtures in `data/fixtures/` and synthetic streams generated by `src/risk_platform/synthetic.py` are 100% original, deterministically seeded synthetic records using tokenized identifiers (`acct_syn_*`, `card_tok_*`, `merch_syn_*`). Zero real card numbers, real customer records, credentials, or proprietary artifacts are included.
