# Fixture Provenance

All datasets and fixtures in `data/fixtures/` and generated by `src/aml_engine/ml/synthetic_data.py` are **100% synthetic**, constructed strictly for educational and software-engineering validation purposes.

- **No real customer data**: All entity IDs (`ENT-*`), account IDs (`ACC-*`), and transaction IDs (`TX-*`) are fabricated alphanumeric tokens.
- **No real financial records**: Monetary amounts, FX rates, timestamps, and scenario typologies are synthetic approximations.
- **No credentials or proprietary artifacts**: Zero API keys, production URLs, or employer/SAAT code or schemas are included.
