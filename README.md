# Machine Learning

## Getting started

```bash
git clone https://github.com/vaibhavkapur/Machine-Learning.git
cd Machine-Learning/projects/Sagemaker-Fraud-Detector
```

Follow the project's [local development instructions](projects/Sagemaker-Fraud-Detector/README.md#local-development) to run the Rails app. Run setup commands from the project directory. For model training and deployment, see the [SageMaker guide](projects/Sagemaker-Fraud-Detector/sagemaker/README.md).

## Projects

- [Sagemaker-Fraud-Detector](projects/Sagemaker-Fraud-Detector/) — A Rails app that scores transactions with XGBoost on AWS SageMaker and uses Redis to cache historical decline rates.
